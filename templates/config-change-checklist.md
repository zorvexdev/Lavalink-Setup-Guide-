# Configuration change checklist

- [ ] Change purpose and expected result are documented.
- [ ] Relevant upstream docs/release notes have been checked.
- [ ] No secret has been added to the diff.
- [ ] YAML syntax and indentation have been checked.
- [ ] Plugin versions are pinned to known values.
- [ ] A rollback version/config exists.
- [ ] Startup logs were reviewed.
- [ ] Search and playback tests passed.
- [ ] Network reachability and logging posture remain intentional.
